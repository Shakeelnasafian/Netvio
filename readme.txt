Netvio is a modern, responsive WordPress theme built with Tailwind CSS. Perfect for businesses, blogs, and creative portfolios. 

== Description ==
Netvio is a clean, fast, and highly customizable theme for WordPress. It features:
- Responsive design
- Custom logo support
- Featured images
- Custom navigation menus
- Modern UI with Tailwind CSS

== Installation ==
1. Upload the theme files to the `/wp-content/themes/netvio` directory, or install the theme through the WordPress theme installer.
2. Activate the theme through the 'Appearance > Themes' menu in WordPress.

== Frequently Asked Questions ==
= Does this theme support the block editor? =
Yes, it works with the WordPress block editor.
